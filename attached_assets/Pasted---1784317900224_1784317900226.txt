مراجعة شاشة البحث عن الرحلات – مطلوب تحسينات عاجلة

يوجد عدد من المشاكل الوظيفية والتصميمية التي يجب إصلاحها بالكامل قبل اعتماد النظام:

أولاً: مشكلة البحث عن المطارات
- عند كتابة اسم الدولة أو المدينة لا تظهر أي اقتراحات للمطارات.
- يجب ربط الحقول بقاعدة بيانات مطارات عالمية حقيقية.
- عند كتابة "السعودية" تظهر مطارات الرياض وجدة والدمام والمدينة وغيرها.
- عند كتابة "الإمارات" تظهر دبي وأبوظبي والشارقة وغيرها.
- يجب دعم البحث باللغة العربية والإنجليزية.
- يجب عرض:
  • اسم المطار الكامل.
  • المدينة.
  • الدولة.
  • رمز المطار (IATA).
- مثال:
  مطار الملك خالد الدولي - الرياض (RUH)
  مطار دبي الدولي - دبي (DXB)

ثانياً: مشكلة اختيار التاريخ
- حالياً لا يظهر تقويم احترافي لاختيار تاريخ السفر.
- يجب استبدال الحقل الحالي بالكامل بمكون Calendar احترافي.
- عند اختيار "ذهاب فقط" يظهر تاريخ المغادرة فقط.
- عند اختيار "ذهاب وعودة" يظهر تاريخ المغادرة وتاريخ العودة معاً.
- يجب أن يكون اختيار التاريخ سهلاً وواضحاً عبر نافذة تقويم حديثة.
- عرض التاريخ الحالي غير احترافي وغير مناسب لتطبيق سفر.

ثالثاً: تحسين تجربة المستخدم UX
- الشاشة الحالية تبدو معقدة نسبياً ولا تعطي إحساس منصة سفر احترافية.
- المطلوب تبسيط خطوات البحث.
- تقليل المساحات الفارغة.
- جعل الحقول أكثر وضوحاً.
- تحسين حجم الأزرار والأيقونات.
- إضافة تأثيرات Hover و Animation ناعمة.
- تحسين ترتيب العناصر ليكون مناسباً للموبايل.

رابعاً: تحسين التصميم UI
التصميم الحالي لا يعكس منصة سفر وسياحة احترافية.

المطلوب:
- تصميم فاخر وعصري مشابه لتطبيقات:
  • Booking.com
  • Almosafer
  • Wego
  • Skyscanner
- استخدام الهوية البصرية الخاصة بالشركة.
- إضافة تدرجات لونية احترافية.
- تحسين البطاقات والظلال.
- تحسين شكل أزرار اختيار درجة السفر.
- جعل حقول البحث أكثر فخامة.
- تحسين شريط التنقل السفلي.
- إضافة أيقونات احترافية متناسقة.

خامساً: مشكلة الرحلات الحقيقية
- حالياً لا توجد رحلات حقيقية.
- النظام يبدو وكأنه يعمل ببيانات وهمية أو تجريبية.
- المطلوب ربط النظام بمزود رحلات حقيقي عبر API.

أمثلة مزودي الرحلات:
- Amadeus API
- Travelport
- Sabre
- Duffel API

يجب أن يوفر النظام:
- رحلات حقيقية مباشرة.
- أسعار حقيقية محدثة.
- شركات الطيران.
- أوقات الإقلاع والوصول.
- مدة الرحلة.
- عدد التوقفات.
- تفاصيل الأمتعة.
- إمكانية الحجز الفعلي.

سادساً: نتائج البحث
بعد الضغط على "بحث عن رحلات" يجب عرض:
- أفضل سعر.
- أسرع رحلة.
- الرحلات الموصى بها.
- فلترة حسب:
  • السعر.
  • شركة الطيران.
  • عدد التوقفات.
  • وقت المغادرة.
  • وقت الوصول.
- ترتيب النتائج حسب السعر أو الوقت.

سابعاً: الأداء
- تسريع البحث.
- إظهار مؤشر تحميل احترافي أثناء البحث.
- عرض رسائل واضحة عند عدم وجود نتائج.
- معالجة جميع الأخطاء بشكل احترافي.

النتيجة المطلوبة:
أريد شاشة بحث رحلات احترافية بمستوى المنصات العالمية، مع مطارات حقيقية، تقويم احترافي، وتجربة مستخدم فاخرة، وربط كامل بمزود رحلات حقيقي يعرض الأسعار والرحلات الفعلية مباشرة للمستخدم.
