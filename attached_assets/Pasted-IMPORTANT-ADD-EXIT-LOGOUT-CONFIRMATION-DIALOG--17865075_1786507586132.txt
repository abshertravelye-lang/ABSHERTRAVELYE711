IMPORTANT — ADD EXIT / LOGOUT CONFIRMATION DIALOG

أريد إضافة تأكيد واضح واحترافي عند محاولة العميل الخروج من الحساب أو التطبيق.

==================================================
1. عند الضغط على زر "تسجيل الخروج"
==================================================

عندما يضغط العميل على زر:

"تسجيل الخروج"

لا يتم تسجيل الخروج مباشرة.

يجب أن يظهر Popup / Confirmation Dialog في منتصف الشاشة:

"هل تريد تسجيل الخروج؟"

وتحتها:

"هل أنت متأكد أنك تريد تسجيل الخروج من حسابك؟"

وتظهر زران واضحان:

[ إلغاء ]

[ تسجيل الخروج ]

إذا ضغط العميل:

"إلغاء"

يتم إغلاق النافذة ويبقى داخل الحساب بدون أي تغيير.

إذا ضغط:

"تسجيل الخروج"

يتم تنفيذ تسجيل الخروج فعلياً، ثم يتم توجيهه إلى صفحة تسجيل الدخول أو الصفحة الرئيسية حسب النظام.

==================================================
2. عند الضغط على زر الرجوع
==================================================

إذا كان زر الرجوع سيؤدي إلى مغادرة التطبيق أو الخروج من الحساب أو إغلاق التطبيق، لا يتم تنفيذ العملية مباشرة.

يظهر Popup:

"هل تريد الخروج؟"

"هل أنت متأكد أنك تريد الخروج من التطبيق؟"

الأزرار:

[ البقاء ]

[ الخروج ]

إذا ضغط:

"البقاء"

يتم إغلاق النافذة ويبقى المستخدم داخل التطبيق.

إذا ضغط:

"الخروج"

يتم تنفيذ الخروج.

==================================================
3. مهم — لا تظهر النافذة في الحالات الطبيعية
==================================================

لا أريد ظهور Popup بشكل مزعج في كل ضغطة على زر الرجوع.

إذا كان المستخدم داخل صفحة عادية ويمكن الرجوع إلى الصفحة السابقة بدون الخروج من الحساب أو التطبيق، يعمل زر الرجوع بشكل طبيعي.

مثال:

صفحة التأشيرات
→ الضغط على رجوع
→ العودة إلى الصفحة السابقة مباشرة.

أما إذا كان الرجوع سيؤدي إلى الخروج من التطبيق أو إنهاء الجلسة، عندها يظهر التأكيد.

==================================================
4. منع الخروج بالخطأ
==================================================

الهدف من هذه الخاصية هو منع العميل من تسجيل الخروج أو مغادرة التطبيق بالخطأ.

لذلك يجب التعامل مع:

- زر تسجيل الخروج داخل الحساب
- زر الرجوع في التطبيق عندما يؤدي إلى الخروج
- زر الرجوع في المتصفح إذا كان سيؤدي إلى مغادرة التطبيق في الحالات المناسبة
- Android Back Button
- Navigation Back
- أي زر Exit موجود في التطبيق

بحيث لا يتم الخروج بشكل مفاجئ في الحالات التي تحتاج تأكيداً.

==================================================
5. إذا كان المستخدم داخل نموذج أو طلب قيد الإنشاء
==================================================

هذه نقطة مهمة جداً.

إذا كان العميل يقوم بتعبئة طلب تأشيرة ولم ينتهِ منه، ثم حاول الرجوع أو مغادرة الصفحة، يجب أن يظهر تحذير مناسب مثل:

"لديك بيانات غير محفوظة"

"إذا غادرت الآن، قد تفقد البيانات التي أدخلتها."

الأزرار:

[ البقاء وإكمال الطلب ]

[ مغادرة الصفحة ]

ولا يتم فقدان البيانات بدون تنبيه.

==================================================
6. إذا كان الطلب قد تم إرساله نهائياً
==================================================

بعد إرسال الطلب بنجاح، لا تظهر رسالة:

"هل تريد الخروج؟"

بسبب الرجوع الطبيعي داخل صفحات النظام إلا إذا كان الرجوع سيؤدي فعلاً إلى مغادرة التطبيق.

أما صفحة تأكيد الطلب النهائي فتحتوي فقط على الخيارات المسموح بها حسب النظام، مثل:

"العودة إلى الرئيسية"

==================================================
7. التصميم
==================================================

أريد Popup احترافي ومتناسق تماماً مع تصميم ABSHER TRAVEL.

يجب أن يحتوي على:

- أيقونة مناسبة
- عنوان واضح
- رسالة قصيرة
- زر إلغاء
- زر تأكيد
- تصميم متجاوب مع الجوال والويب
- دعم اللغة العربية
- دعم RTL

ولا أريد نافذة Browser Alert قديمة أو رسالة JavaScript عادية.

يجب أن يكون Dialog / Modal حقيقياً من تصميم النظام.

==================================================
8. تسجيل الخروج من Backend
==================================================

عند اختيار:

"تسجيل الخروج"

يجب تنفيذ Logout بشكل صحيح من النظام الحالي.

ولا يكفي فقط حذف بيانات من Frontend إذا كان النظام يستخدم جلسات أو Tokens تحتاج إلى إبطال أو إنهاء بشكل صحيح.

==================================================
9. Web + Mobile
==================================================

يجب تطبيق نفس المنطق على:

ABSHER TRAVEL Web Platform
+
ABSHER TRAVEL Mobile Application

مع مراعاة طريقة الرجوع الخاصة بكل منصة.

Android:
زر الرجوع في الجهاز.

iOS:
Navigation Back / Swipe Back عند الحاجة.

Web:
زر الرجوع والتنقل داخل المنصة عند الحالات التي تتطلب تأكيداً.

==================================================
10. النتيجة المطلوبة
==================================================

أريد أن يكون سلوك النظام واضحاً:

تسجيل الخروج
→ Popup
→ "هل تريد تسجيل الخروج؟"
→ إلغاء / تسجيل الخروج

الرجوع العادي
→ رجوع طبيعي

الرجوع الذي يؤدي إلى الخروج
→ Popup
→ "هل تريد الخروج من التطبيق؟"
→ البقاء / الخروج

وجود بيانات غير محفوظة
→ Popup تحذيري
→ "لديك بيانات غير محفوظة"
→ البقاء / مغادرة الصفحة

لا أريد أي خروج مفاجئ أو فقدان بيانات بدون تحذير.

نفذ هذه الخاصية داخل النظام الحالي وبنفس الهوية والتصميم المستخدم في ABSHER TRAVEL، وليس كنافذة تجريبية منفصلة.
