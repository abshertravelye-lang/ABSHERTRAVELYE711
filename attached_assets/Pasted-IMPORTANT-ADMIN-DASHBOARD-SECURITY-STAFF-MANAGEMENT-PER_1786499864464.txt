==================================================

The Admin Dashboard is currently accessible without proper authentication.

Create a secure Admin Login page with:

- Email / username

4. IMPORTANT — EMPLOYEE ACCESS MUST BE LIMITED
==================================================

This is a critical requirement.

DO NOT give every employee access to the entire Admin Dashboard.

Each employee must ONLY have access to the sections and actions assigned to them by the Super Admin.

For example:

A Visa Employee should only be able to work with visa applications and the information necessary to process those applications.

A Customer Support Employee should only be able to work with customer messages and the customer information necessary for support.

A Flight Employee should only be able to work with flight requests.

A Hotel Employee should only be able to work with hotel requests.

Employees MUST NOT automatically have access to:

- Employee Management
- System Settings
- Visa Configuration
- Other employees' accounts
- Permission Management
- Sensitive administrative functions

unless the Super Admin explicitly grants that permission.

The employee dashboard should therefore be personalized according to the employee's permissions.

IMPORTANT:

Hiding menu items is NOT enough.

The backend/API MUST enforce the same permissions.

If an employee manually enters a restricted URL, the request MUST be rejected.

If an employee directly calls a restricted API endpoint, the request MUST be rejected.

Employees MUST NEVER be able to bypass permissions through the frontend.
