I want to completely change the “Contact Us” feature.

DO NOT redirect the customer to WhatsApp or any external application.

If the customer is logged in, the system must automatically identify the customer's name from their account.

For example:

Hello Ali 👋
Welcome to ABSHER TRAVEL.
How can our support team help you today?

Then display the message input field so the customer can start chatting immediately.

Do not ask the customer for their name again if their name already exists in their account.

2. Guest / Not Logged In

If the customer is not logged in, the chat should immediately ask:

Welcome to ABSHER TRAVEL 👋
Please provide your name to start the conversation.

Show:

Your Name

and a:

Continue

button.

After entering the name, the customer can immediately start chatting with the support team.

3. REAL CHAT SYSTEM

This must be a real functional support chat, not a visual/demo interface.

It must be connected to:

Existing Backend
API
PostgreSQL Database
User Accounts
Admin Dashboard

The customer must be able to:

Send messages
Receive replies
View previous messages
Continue an existing conversation
Close and reopen the app without losing the conversation

The support team must be able to:

Receive customer messages
Reply to customers
View the customer's name
View the customer's account information if logged in
View the complete conversation history
Manage conversations from the Admin Dashboard
4. Admin Dashboard

Admin Dashboard → Support Chat

Customer name
Customer account
Conversation
Messages
Message date/time
Conversation status
Unread messages

5. Notifications

When the support team replies to a customer:

Show an in-app notification.
Send a Push Notification to the customer's phone.
The notification must appear even when the app is running in the background.
The notification should be branded as ABSHER TRAVEL.
Tapping the notification must open the specific support conversation.

Example:

ABSHER TRAVEL

User → Support Conversation → Messages

For guests, the conversation can initially be associated with the name they provide. If they later create/login to an account, the system should be able to associate the conversation with their account where appropriate.

ABSHER TRAVEL Mobile Application

If they start on Web, they must be able to continue it from Mobile.
