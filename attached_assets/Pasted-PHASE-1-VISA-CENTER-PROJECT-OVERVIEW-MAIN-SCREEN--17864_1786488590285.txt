PHASE 1
VISA CENTER - PROJECT OVERVIEW & MAIN SCREEN
======================================================================

Project Goal

Build a world-class Visa Center that provides the fastest, easiest, and most professional visa application experience in the Middle East.

The Visa Center must have a premium UI/UX, modern architecture, intelligent automation, and a smooth user journey that minimizes user effort.

The system should be significantly more advanced than traditional visa platforms by reducing manual input, increasing automation, and simplifying every application step.

======================================================================
GENERAL CONCEPT
======================================================================

The visa system should rely on the customer's Profile.

The customer creates and completes their profile only once after registration.

The profile stores all personal information, passport information, residency information, contact information, and any required permanent data.

Whenever the customer applies for any visa, the system automatically retrieves all profile information without requiring the customer to enter the same information again.

The visa application process should only require uploading the required documents, reviewing the application, selecting the payment method, and submitting the application.
