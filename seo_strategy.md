# SEO Strategy — Absher Travel (أبشر أعمال للسفريات والسياحة)

## In scope
- Public-facing travel website: `artifacts/absher-travel` (served at `/`)
- Public pages: Home, Destinations, Destination Detail, Offers, Programs, Visas, Visa Country Detail, Visa Detail, About, Contact, Flights, Hotels

## Out of scope
- Admin dashboard (`artifacts/absher-admin`, `/admin/*`) — internal staff tool
- Authenticated account pages (`/account/**`) — require login
- Mobile app (`artifacts/absher-mobile`) — native app, not indexed by web crawlers
- API server (`artifacts/api-server`) — backend, not public HTML

## Target audience
- Arabic-speaking travelers seeking flights, hotels, visas, and tourism packages (primary)
- English-speaking travelers (secondary)
- Saudi/Arab market emphasis (Umrah, visa applications)

## Primary keywords
- Travel packages (رحلات سياحية)
- Visa services (خدمات التأشيرة)
- Umrah programs (برامج العمرة)
- Flight booking (حجز طيران)
- Hotel booking (حجز فنادق)

## Rendering mode
- SPA (React + Wouter) — content rendered client-side only
